# woolmer.info

Coming soon page for woolmer, the independent Whitehill & Bordon guide. Plain HTML, no build step.
Hosted on GitHub Pages with the custom domain in `CNAME`; DNS for woolmer.info is managed at Wix.

The full design and the locked mockup live in the dunnworks repo under `sites/wb-guide`
(preview at dunnworks.io/preview/wb-guide/).

Colours: Blue Zodiac #0C243C, Tiara #C9D1D5, Fountain Blue #55C2C3, orange #FF862F for the tree logo
and headings on dark, #C4550F for headings on light backgrounds.
